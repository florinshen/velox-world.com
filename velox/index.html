Velox

Spatial memory makes long‑context world models efficient.

  • Qiuhong Shen
  • Shizun Wang
  • Xinchao Wang

National University of Singapore

Interactive world models have to remember what they have already generated, but dense attention over a growing history makes every new chunk slower. Velox is a training-free attention router: camera frustum slabs from streaming geometry tell each region of the video which parts of the past it actually needs.

01 · The problem

A world model that remembers pays for it on every chunk.

Long-horizon generation needs persistent visual history, so chunked video world models keep it in a growing KV cache.

An infinite window lets every current block attend to every retained block, even though the camera can only see a small part of the past. Later chunks get progressively slower, which is exactly wrong for interaction. Frame memory retrieves whole past views, which is coarse.

The fix is not to forget. It is to route: keep the memory, and expose each query block to a bounded set of the blocks that matter.

02 · Method

Route by where things are, guided by what the model already wants.

Velox leaves the generator and its conditioning interface untouched and changes only the inference-time visibility between current query blocks and historical KV blocks.

01

Remember as frustum slabs

After each chunk, streaming geometry turns every historical KV block into slabs: a source-camera token rectangle with a robust depth interval.

02

Give the new block a depth

Several cached depth frames are warped forward into the target camera, so each query block gets a depth interval of its own.

03

Let overlap nudge, not decide

Fully covered blocks use a geometry-weighted route with a small budget (80). Blocks that are not fully covered keep the plain block-sparse route with a larger budget (150).

04

Run a bounded route

A fixed-size block list, plus the previous chunk and Gilbert-curve neighbours, feeds a block-sparse kernel that matches FlashAttention tiles.

Covered and uncovered blocks. Well-covered query blocks use the fused route (K = 80). Blocks without enough geometric coverage, such as sky or newly exposed regions, keep the model-only route (capped at K = 150). The previous chunk is always retained, and Gilbert-curve neighbours act as deterministic safeguards.

What the router sees

For a query block, multiwarp provides a depth map, and the best-matching historical blocks are found by slab overlap. When the camera revisits a place, the matches come from chunks far in the past.

Why the route is a block, not a token

FlashAttention streams fixed Q and K/V tiles. A token-wise mask cuts across many tiles, so most are still loaded. A block route keeps or skips whole tiles before the kernel runs.

Keeping neighbours adjacent in the block order

A Gilbert (space-filling) order keeps spatially and temporally adjacent tokens adjacent in the flattened sequence, which keeps sparse blocks local. Applied chunk by chunk it breaks temporal adjacency; flipping the mapping horizontally on alternate chunks restores it.

03 · Results

Late chunks get much cheaper. Aggregate quality stays near dense.

Runtime is measured over a 48-chunk rollout on a single H200, with geometry construction running asynchronously on the same GPU. Quality is measured on WBench, a multi-turn benchmark for interactive world models, over its 158 navigation cases of 16 to 48 generated chunks.

Bounded memory, bounded cost. Dense FlashAttention schedules every current–history tile pair. Velox schedules only the routed blocks, so a skipped block removes both the QKᵀ product and the KV load.

Geometry adds value beyond sparsity. Against a matched model-only block-sparse route, soft fusion lifts the API-free average from 73.11 to 73.51 and the overall average from 75.01 to 75.60. Dense stays marginally ahead on the API-free average, by 0.15 points, and ahead on some individual metrics; the table shows all of them.

Geometry and the model agree. On calibration scenes, blocks with positive slab overlap land in the model's own top-50 far more often than chance: Rgeo = 0.73 at layer 14, against a random expectation of 0.35. Fusion at λ = 2 raises top-80 positive-overlap recall from 0.60 to 0.85 while changing 9.0% of selected blocks.

Scope. Timings are for the reported single-H200 asynchronous implementation on LingBot-Fast-Cam. The paper does not claim wall-clock superiority in every setting.
