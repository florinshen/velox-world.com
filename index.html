01 · Vision

Physical AI needs a world it can rehearse in.

Robots, vehicles and simulators act in a world where trying everything is slow, costly or unsafe. A world model lets an agent imagine what happens next before it commits. That only works if the imagination is consistent over long horizons, trained toward what matters, and fast enough to sit inside the control loop.

  1. 01

    Consistent

    Stay coherent as the horizon grows: remember what has been seen, and recognise it when the camera or the agent comes back.

    Velox →
  2. 02

    Aligned

    Be trained toward the signals that matter, with reinforcement learning cheap enough that we can actually iterate on it.

    RPO →
  3. 03

    Real-time

    Meet a latency budget. Memory, attention and training all have to be efficient before a world model can be used inside a loop.

02 · Research

Making world models cheap enough to run live.

Real-time interaction is both a systems problem and a learning problem. Our first two projects work on each end: how a world model remembers at inference time, and how a visual generator is aligned at training time.
